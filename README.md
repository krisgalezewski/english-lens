# EnglishLens 📰

A Progressive Web App delivering weekly curated English news for Polish learners, with B1 and B2–C1 summaries generated by Claude AI.

---

## How it works 

Every Monday at 07:30 Warsaw time, a GitHub Actions workflow:
1. Fetches headlines from 12 RSS feeds (BBC, Reuters, Euronews, Politico EU, Notes from Poland, The Guardian)
2. Filters articles for relevance to Polish/Central European readers
3. Selects ~10 articles balanced across categories
4. Generates B1 and B2–C1 summaries + key vocabulary for each
5. Commits the updated `public/news.json` to the repo
6. GitHub Pages automatically serves the updated PWA

## Setup

### 1. Fork / clone this repo

### 2. Enable GitHub Pages
- Go to **Settings → Pages**
- Source: **Deploy from a branch**
- Branch: `main` / folder: `/public`
- Save — your site will be at `https://YOUR-USERNAME.github.io/REPO-NAME/`

### 3. Add your Anthropic API key
- Go to **Settings → Secrets and variables → Actions**
- Click **New repository secret**
- Name: `ANTHROPIC_API_KEY`
- Value: your key from [console.anthropic.com](https://console.anthropic.com)

### 3b. Add your YouTube API key (for the Videos tab)
- Go to [console.cloud.google.com](https://console.cloud.google.com)
- Create a new project (or use an existing one)
- Search for **"YouTube Data API v3"** and click **Enable**
- Go to **Credentials → Create Credentials → API key**
- Copy the key
- Back in your GitHub repo: **Settings → Secrets and variables → Actions → New repository secret**
- Name: `YOUTUBE_API_KEY`
- Value: the key you just copied

This is optional — if you skip it, the article Lens works exactly as before, the Videos tab will just stay empty.

### 4. Test manually
- Go to **Actions → Weekly News Fetch → Run workflow**
- Watch the logs — it should complete in ~3 minutes
- Check `public/news.json` was updated

### 5. That's it
The workflow runs automatically every Monday. You don't need to touch it.

## Customising

### Change the schedule
Edit `.github/workflows/weekly-fetch.yml`:
```yaml
- cron: '30 5 * * 1'   # 05:30 UTC = 07:30 Warsaw (summer)
```
Use [crontab.guru](https://crontab.guru) to adjust timing.

### Add or remove feeds
Edit the `FEEDS` array in `fetch-news.js`. Each entry needs:
```js
{ url: 'RSS_FEED_URL', category: 'politics|business|technology|environment|culture', name: 'Display Name' }
```

### Change number of articles
In `fetch-news.js`:
```js
const ARTICLES_PER_RUN = 10;  // total articles
const MAX_PER_CATEGORY = 3;   // max from any one category
```

### Winter/summer time
The workflow uses `05:30 UTC`. This equals:
- **Summer (CEST, UTC+2)**: 07:30 Warsaw ✓
- **Winter (CET, UTC+1)**: 06:30 Warsaw

To fix winter timing, change the cron to `30 6 * * 1` in October, and back to `30 5 * * 1` in March. Or use two separate scheduled jobs.
